This is the reading list that sits behind [Future-proofing front-end dev roles](/blog/future-proofing-front-end-dev-roles). That post argues the role is shifting toward judgment, systems thinking, and verification. This one lists what to read to build those skills.

The list isn't meant to be finished front to back. Pick the two or three entries that match whatever you're weakest at right now.

## Courses

[Frontend Masters](https://frontendmasters.com/) has the broadest catalog, including a dedicated [Coding with AI Learning Path](https://frontendmasters.com/learn/ai/). [Epic React](https://www.epicreact.dev/) and [Epic Web](https://www.epicweb.dev/) (Kent C. Dodds) go deep on application architecture and testing. [Total TypeScript](https://www.totaltypescript.com/) (Matt Pocock) is the reference for the type-level depth that now doubles as agent guardrails.

For CSS, React, and visual design: [CSS for JS Developers](https://css-for-js.dev/) and [The Joy of React](https://www.joyofreact.com/) (Josh Comeau), [web.dev/learn](https://web.dev/learn/), [MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development), [Refactoring UI](https://www.refactoringui.com/), and [Build UI](https://buildui.com/).

For accessibility and design systems, two areas where AI output is weakest: [Practical Accessibility](https://practical-accessibility.today/) (Sara Soueidan) and [AI and Design Systems](https://aianddesign.systems/) (Brad Frost). [DeepLearning.AI short courses](https://www.deeplearning.ai/courses/) cover the model side if you're building AI features rather than just using AI tools.

## Books

[Refactoring UI](https://www.refactoringui.com/), [Inclusive Components](https://book.inclusive-components.design/) (Heydon Pickering), [Atomic Design](https://atomicdesign.bradfrost.com/) (Brad Frost, free online), [Eloquent JavaScript](https://eloquentjavascript.net/) (free online), and Addy Osmani's [Beyond Vibe Coding](https://beyond.addy.ie/).

## Newsletters and blogs

Publications: [Smashing Magazine](https://www.smashingmagazine.com/), [JavaScript Weekly](https://javascriptweekly.com/), [Frontend Focus](https://frontendfoc.us/), [Bytes](https://bytes.dev/), [web.dev](https://web.dev/), [Chrome for Developers](https://developer.chrome.com/blog/), [The Pragmatic Engineer](https://newsletter.pragmaticengineer.com/), and [Simon Willison's Weblog](https://simonwillison.net/).

People to follow directly: Addy Osmani, Josh Comeau, Una Kravets, Adam Argyle, Stephanie Eckles, Brad Frost, Adrian Roselli, and Sara Soueidan.

## Podcasts

[Syntax](https://syntax.fm/), [ShopTalk Show](https://shoptalkshow.com/), [Front End Happy Hour](https://www.frontendhappyhour.com/), [devtools.fm](https://www.devtools.fm/), and [Latent Space](https://www.latent.space/) for the AI-engineering side.

## AI-specific resources

Primary documentation ages better than commentary here, so start with the source: [Anthropic Build with Claude](https://www.anthropic.com/learn/build-with-claude), the [Anthropic Cookbook](https://github.com/anthropics/anthropic-cookbook), the [Prompt Engineering Interactive Tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial), and the [OpenAI Cookbook](https://cookbook.openai.com/).

For building features: [Vercel AI SDK docs](https://ai-sdk.dev/docs/introduction) and [LangChain.js docs](https://js.langchain.com/). For the protocol layer and agent tooling: [Model Context Protocol docs](https://modelcontextprotocol.io/), [Claude Code overview](https://code.claude.com/docs/en/overview), GitHub Copilot's enterprise documentation, and the OpenAI Codex docs and evals guides.

## Annual industry reports

These are worth reading once a year, because they show long-term trends rather than short-term news: the Stack Overflow Annual Developer Survey, GitHub's Octoverse, JetBrains' State of the Developer Ecosystem, Microsoft's Work Trend Index, [DORA research](https://dora.dev/), and the World Economic Forum's Future of Jobs report.
