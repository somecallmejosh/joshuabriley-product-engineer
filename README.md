# joshuabriley.com

The personal site and portfolio of **Joshua Briley**, a Product Design Engineer who builds full-stack products and design systems. Static-generated with [Astro](https://astro.build), deployed to Netlify, and built around a hand-tuned "Editorial-Technical" design system.

## Highlights

- **Editorial-Technical design system** — one warm grotesk (Hanken), a display serif for character (Newsreader), and a mono for technical moments (Geist Mono). Monochrome neutrals with a single surface-aware accent that shifts between light and ink surfaces.
- **Case studies & projects** — client work (IVFCRYO, VMSpark, Logatot) and personal projects (Rudiment UI, Token Adventure, West Baton Rouge Presbyterian).
- **Content collections** — blog posts (`.mdx`), tools (`.mdx`), and testimonials (`.json`) are type-checked via Zod schemas in `src/content.config.ts`.
- **Interactive tools** — four live islands (scorecard, ROI calculator, token playground, audit inspector) render above their essays under `/tools/`.
- **Accessibility-first** — WCAG AA contrast is enforced by live audit scripts and Playwright + axe-core e2e coverage.
- **Auto-generated OG cards** — per-page social images are rendered from a manifest and regenerated by a git pre-commit hook when their inputs change.

## Tech stack

## Getting started

```bash
npm install          # also sets git hooksPath via the `prepare` script
npm run dev          # start the dev server at http://localhost:4321
```

> **Note:** the Netlify adapter makes `npm run preview` unsupported for local iteration. Use `npm run dev` (`astro dev` on `:4321`) for local work, screenshots, and the audit/OG scripts.

## Scripts

| Command                    | What it does                                                       |
| -------------------------- | ----------------------------------------------------------------- |
| `npm run dev`              | Start the Astro dev server (`:4321`).                             |
| `npm run build`            | Build the static site to `dist/`.                                 |
| `npm run check`            | Run `astro check` (TypeScript + content schema validation).       |
| `npm test`                 | Vitest unit tests for pure helpers in `src/lib/`.                 |
| `npm run test:e2e`         | Playwright e2e + axe-core accessibility scan.                     |
| `npm run og:generate`      | Regenerate per-page OG cards (needs a dev server on `:4321`).     |
| `npm run audit:design`     | Fail on design-system drift against `design-system/` (see its README). |
| `npm run audit:contrast`   | WCAG contrast audit of design-system token pairs.                |
| `npm run audit:style-guide`| Live WCAG audit of the rendered `/style-guide/` page.            |

## Content

- **Add a blog post** — drop an `.mdx` file in `src/content/posts/`. Frontmatter must satisfy the `posts` schema in `src/content.config.ts` (title, description, date, category, readMinutes, icon, gradient, sticker; `draft: true` hides it from listings).
- **Add a tool** — drop an `.mdx` file in `src/content/tools/` matching the `tools` schema. Its `tool` field must name a key of `ISLANDS` in `src/layouts/ToolPage.astro`.
- **Add a testimonial** — add a numbered `.json` file in `src/content/testimonials/` matching the `testimonials` schema.

## Routing & redirects

Routes are file-based under `src/pages/`. Legacy paths (the old `/tools/*` and `/scorecard` routes, plus moved projects) are preserved via `redirects` in `astro.config.mjs` so existing links and SEO stay intact.

## OG image generation

Per-page Open Graph cards live in `public/images/og/` and are rendered from the manifest in `src/lib/og-pages.mjs`. A git pre-commit hook (`.githooks/pre-commit`, wired up by the `prepare` npm script) regenerates them only when an OG input is staged. Bypass with `git commit --no-verify`; regenerate manually with `npm run og:generate` (dev server on `:4321` required).

## Deployment

Pushing to the default branch builds and deploys to Netlify. The Netlify adapter is applied for builds and skipped in `dev` (see `astro.config.mjs`).
