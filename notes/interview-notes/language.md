# Post writing style

Each post should use the simplist possible language. When a technical word can be replaced by a non technical word that a non technical person can understand, choose the non technical word. Don't assume the reader has any sort of prior knowledge or technical savvy.

Avoid cheeky headlines. They can distract the reader. Don't make the user think about what the meaning behind the content is.

Use as few words and sentences as possible. The reader should be able to comfortably read the content in five to ten minutes.

Absolutely no LLM style writing. It should read as close to human language as possible.
